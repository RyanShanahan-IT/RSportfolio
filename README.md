# Ryan Shanahan - Enhanced Portfolio Website

A modern, responsive portfolio website showcasing my skills, projects, and professional experience as a Computer Science graduate.

## ✨ Features

### 🎨 **Modern Design**
- **Gradient-based color scheme** with professional aesthetics
- **Dark/Light mode toggle** with persistent user preferences
- **Smooth animations** and hover effects throughout
- **Responsive design** optimized for all devices

### 🚀 **Enhanced User Experience**
- **Smooth scrolling navigation** with active section highlighting
- **Loading animations** for project cards and skill sections
- **Interactive elements** with hover effects and transitions
- **Custom notifications** instead of basic browser alerts

### 📱 **Mobile-First Responsiveness**
- **Adaptive layouts** for all screen sizes
- **Touch-friendly navigation** and interactions
- **Optimized media** display for mobile devices
- **Floating action buttons** for mobile users

### 🎯 **Professional Content**
- **Project showcase** with multimedia content (videos, images, diagrams)
- **Skills demonstration** with interactive cards and icons
- **Professional credentials** and certifications
- **Clear call-to-action** sections

## 🛠️ Technical Implementation

### **Frontend Technologies**
- **HTML5** - Semantic markup and accessibility
- **CSS3** - Modern styling with CSS Grid, Flexbox, and animations
- **JavaScript (ES6+)** - Interactive functionality and smooth animations
- **Font Awesome** - Professional iconography

### **Key Features**
- **Intersection Observer API** for scroll-based animations
- **Local Storage** for user preferences
- **CSS Custom Properties** for dynamic theming
- **Progressive Enhancement** for better accessibility

### **Performance Optimizations**
- **Efficient animations** using CSS transforms
- **Lazy loading** for media elements
- **Smooth transitions** with hardware acceleration
- **Optimized event handling** for better responsiveness
