Bakery Scramble

A fast-paced merge puzzle game built around a 4×4 ingredient grid, released on Android after an earlier Unity web version.

What I built
I built and published the game, brought the web version to Android, and added ingredient merging, difficulty modes and high-score tracking.
How I approached it
I used a small grid and drag-and-drop controls to keep the game easy to pick up. Different difficulty modes and spawn rates change the pace.
The result
I released a web version and an Android game. You can try it yourself or watch the gameplay below.
